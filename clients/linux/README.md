# GoreeCloud Mail Linux Client

This directory contains the Linux desktop client foundation.

The Linux client target is a first-party GoreeCloud application distributed through Debian-compatible packaging.

Goals:

- Native desktop integration
- Desktop notifications
- mailto handling
- Secure local cache management
- Offline synchronization support
- Shared GoreeCloud Mail backend compatibility

The Debian package pipeline will generate release artifacts after the desktop runtime, signing, packaging metadata, and acceptance validation are complete.
